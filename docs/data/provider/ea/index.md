## License

The Hydrology API describes its data as published under the
[UK Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/)
("licenseName": "OGL 3"; the reference page ends with "© Crown Copyright 2024"). The Environment Agency's page of terms
and conditions that this page used to link, on support.environment.data.gov.uk, is gone: the host no longer resolves
(checked 2026-11-06), and no new address is known. Its
[Hydrology API reference](https://environment.data.gov.uk/hydrology/doc/reference) has a section "Data volume and fair
use", which asks that "users who are automatically downloading bulk data ... limit the number of non-batch API requests
they make at any one time. Ideally limit to one request in flight at a time, waiting for each request to finish before
issuing the next", and says the Environment Agency reserves "the right to enforce limits on the number of concurrent
requests (per IP address or identifiable group of IP addresses)" and may "block users who place excessive demands on the
service to the detriment of other users". It also sets a hard limit of 2,000,000 rows a call, "subject to review", and
offers a batch API for more. The OGL asks for an attribution statement; the page gives none beyond the licence.
