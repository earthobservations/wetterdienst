Notices for code in the DuckDB files the browser downloads (GH-3469)

@duckdb/duckdb-wasm 1.33.1-dev57.0 was built from duckdb-wasm main after "Bump to duckdb v1.5.4"; its WASM modules
carry the DuckDB source id 08e34c447b, which is commit 08e34c447bae34eaee3723cac61f2878b6bdf787 of
github.com/duckdb/duckdb, the tag v1.5.4. The package ships no licence text, so the texts below are those
files of that commit, copied as they are: DuckDB's own LICENSE, the LICENSE of every directory of its
third_party/ folder and of the ICU copy, which the WASM module links statically (the build selects among them;
the package does not say which, so all are listed). The worker (duckdb-browser-eh.worker.js) bundles js-sha256
and the browser stub of ws; their LICENSE files are from the npm packages (js-sha256 0.11.1, which the worker
names in its own comment; ws 8.22.0, the version in this app's lockfile, the stub itself has no version).
