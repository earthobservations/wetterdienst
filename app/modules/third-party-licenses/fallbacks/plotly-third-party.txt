Notices for libraries bundled in plotly-basic.min.js (GH-3469)

plotly.js 3.7.0 bundles its dependencies into the file and the app's minifier drops their licence comments;
the file keeps only the block at its end for native-promise-only, polybooljs and object-assign, which is
reproduced with the package. The texts below are the LICENSE files of the npm packages, at the version
plotly.js 3.7.0 pins or, where it asks for a range (d3-time ^1.1.0, tinycolor2 ^1.4.2, base64-arraybuffer
^1.0.2, is-mobile ^4.0.0), at the lowest version of the range, for the libraries that can be identified in
the minified file by their own code:
@plotly/d3 3.8.2 (its version string), d3-format 1.4.5 and d3-time-format 2.2.3 (the file links to these versions of them, and carries d3-time-format's locale),
d3-time 1.1.0 (its interval constants), tinycolor2 (window.tinycolor), base64-arraybuffer and is-mobile.

NOT reproduced: the notices of the other libraries plotly.js bundles for its "basic" bundle, which cannot be
told apart in a minified file without its sources (plotly.js 3.7.0 depends on fast-isnumeric, has-hover,
has-passive-events, mouse-event-offset, point-in-polygon, color-normalize and color-rgba (and what they
pull in), parse-svg-path, world-calendars, topojson-client and others, of which some may be in this bundle).
Their licences are those of the npm packages of those names; this file does not reproduce them.
