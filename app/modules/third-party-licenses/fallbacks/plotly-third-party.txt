Notices for libraries bundled in plotly-basic.min.js (GH-3469)

plotly.js 3.7.0 bundles its dependencies into the file, and the app's minifier drops their licence comments; the
file keeps only the block at its end for native-promise-only, polybooljs and object-assign, which is reproduced
with the package. The unminified file of the same release, plotly.js-basic-dist 3.7.0, marks each bundled module
with a "// node_modules/<package>/..." comment, and the 22 packages it names are listed here:
@plotly/d3 3.8.2, base64-arraybuffer 1.0.2, d3-format 1.4.5, d3-time 1.1.0, d3-time-format 2.2.3, events 3.3.0, fast-isnumeric 1.1.4, gl-mat4 1.2.0, has-hover 1.0.1, has-passive-events 1.0.0, is-browser 2.1.0, is-mobile 4.0.0, is-string-blank 1.0.1, maplibre-gl 4.7.1, mouse-event-offset 3.0.2, native-promise-only 0.8.1, object-assign 4.1.1, parse-svg-path 0.1.2, point-in-polygon 1.1.0, polybooljs 1.2.2, tinycolor2 1.4.2, world-calendars 1.0.4.
Each text is the licence file of the npm package at the version plotly.js v3.7.0's package-lock.json resolves, with
these exceptions:
- is-mobile 4.0.0 and has-hover 1.0.1 ship no licence file. The text given is the current file of their
  repositories (LICENSE of juliangruber/is-mobile; `license` of dy/has-hover). The README.md of the is-mobile
  4.0.0 package carries the same MIT terms (copyright 2013 Julian Gruber).
- native-promise-only 0.8.1 has no licence text of its own below: neither its package nor its repository ships a
  licence file. Its README states the MIT licence and points to http://getify.mit-license.org/, and the
  "Bundled license information" block that the minified file keeps, reproduced at the end of this
  entry, names the same licence with the copyright line "(c) Kyle Simpson".
- maplibre-gl 4.7.1: the bundle embeds only maplibre-gl/dist/maplibre-gl.css (injected at runtime), not its
  JavaScript; the text given is the package's root LICENSE.txt.
